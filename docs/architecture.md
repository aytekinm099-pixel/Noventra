# Noventra Architecture v1

## Overview

Noventra is a multi-chain Web3 Trust & Lock Intelligence platform.

Its primary purpose is to aggregate token lock, liquidity lock, vesting and unlock data from multiple blockchain ecosystems into a single platform.

Noventra provides transparency for investors, developers and communities.
